## Colors

| Token | Hex | Usage |
|-------|-----|-------|
| Primary accent | `[[#PRIMARY]]` | Headers, active indicators, key highlights |
| Secondary accent | `[[#SECONDARY]]` | Links, badges, info elements |
| Text | `#18181b` | Body text on light backgrounds |
| Page background | `#ffffff` | Default page background |
| Subtle background | `#fafafa` | Card hover, alternating rows |

Rule of two: pick one to two accent colors per page. Resist using all of them.

## Typography

- Body font: `'Inter', -apple-system, BlinkMacSystemFont, sans-serif`
- Anti-alias: always set `-webkit-font-smoothing: antialiased`
- Weights: 400 body, 600 labels, 700 headings, 800 hero

## What to Always Do

- Start every page with a small uppercase label above the bold heading
- Light theme as default. Dark only if user explicitly asks
- Cite sources at the bottom of any data-heavy output
- Use plain language. Glossary the jargon

## What to Never Do

- No em dashes in text. Use commas, periods, or restructure
- No emoji unless asked
- No marketing superlatives ("revolutionary", "game-changing")
- No filler like "delve", "in today's fast-paced world", "ever-evolving landscape"

## Sample Outputs

When asked to draft a [[email / memo / slide / report]], always:

1. Lead with the headline message in one sentence
2. Give the three reasons or facts that support it
3. Close with the action or decision needed

This skill applies to any text output unless the user explicitly overrides it.
